# OligoTools feedback

Public feedback, bug reports and feature requests for [OligoTools](https://oligo-tools.vercel.app/), developed by [Peter Pečan](https://github.com/peterpecan).

[Submit feedback or a feature request](https://github.com/peterpecan/OligoTools-feedback/issues/new/choose) or [browse existing issues](https://github.com/peterpecan/OligoTools-feedback/issues).

This repository hosts the public issue tracker. The application source code is maintained separately in a private repository.

Search existing issues before opening a new one. For bugs, include the page or workflow, steps to reproduce, expected and observed behavior, and your browser. For feature requests, describe the research task and what would help.

Issues and attachments are public. Use a minimal, non-sensitive example and remove confidential sequences, unpublished research and personal information from screenshots or exported files before sharing them.
